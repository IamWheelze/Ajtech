# Assets Images

This folder should contain images for the AJ Tech website.

## Required Images

Please add the following images to make the website fully functional:

1. **phone-placeholder.jpg** - Image of smartphones for the products section
2. **laptop-placeholder.jpg** - Image of laptops for the products section
3. **used-phone-placeholder.jpg** - Image of used/refurbished phones
4. **accessories-placeholder.jpg** - Image of phone/laptop accessories
5. **about-placeholder.jpg** - Image for the about section (team photo or store image)

## Image Specifications

- **Format**: JPG or PNG
- **Recommended size**: 800x600 pixels minimum
- **Aspect ratio**: 4:3 or 16:9 for product images
- **File size**: Keep under 500KB for optimal loading

## Note

The website has been designed to handle missing images gracefully. If images are not available, placeholder gradients will be displayed automatically.

To use your own images, simply add them to this folder with the exact filenames listed above.
